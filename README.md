# 3D-thing

**Skyshard**: a small 3D platformer made with [Three.js](https://threejs.org/). Roll a ball across floating sky islands, collect all 15 shards, dodge the spiky critters, and try to beat your best time.

## Play

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000
```

Three.js loads from a CDN, so you need an internet connection.

## Controls

| Key | Action |
| --- | --- |
| W A S D / arrow keys | Move (relative to the camera) |
| Space | Jump (press again mid-air to double jump) |
| Mouse | Look around (the pointer locks once you click to play) |
| Q / E | Turn the camera without the mouse |
| Esc / P | Pause |
